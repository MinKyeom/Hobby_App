# Play Console — Data safety 답변 요약

앱은 **서버로 사용자 개인정보를 수집하지 않습니다.**  
SDK·권한을 바꾸면 이 문서와 `DATA_SAFETY.md`를 함께 수정하세요.

| 질문 | 답변 |
|------|------|
| 사용자 데이터를 수집·공유하나요? | **아니요** |
| 수집하는 데이터 유형 | 없음 |
| 개인정보·금융·건강·위치·연락처 등 | 수집 안 함 |
| 사진·동영상 | 앱이 **수집·업로드하지 않음**. 사용자가 결과 카드를 **기기에만** 저장할 수 있음 |
| 광고 ID | **사용 안 함** |
| 분석·광고 SDK | **없음** |
| 계정 | 없음 → 계정 삭제 요청 해당 없음 |
| 전송 중 암호화 | 서버 전송 없음 → 해당 없음에 가깝게 응답 |
| 데이터 삭제 | 앱 삭제 또는 「다시하기」로 기기 세션 삭제 |

### 권한 설명 (설문/정책)

- 사진/미디어: **결과 카드 저장 전용**, 기존 미디어 읽기·업로드 없음  
- 위치·마이크·카메라·연락처: **사용 안 함** (`app.json` blockedPermissions)
